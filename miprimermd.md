\# Mi primer documento Markdown



\## Introducción a Markdown



Markdown es un lenguaje de marcado ligero que permite estructurar y dar formato a documentos de texto de forma sencilla. \*\*Este texto está en negrita\*\*, \*este texto está en cursiva\* y esto está escrito en `código`.



\### Trozo de código



```python

def saludar(nombre):

&#x20;   print(f"Hola, {nombre}")

```
